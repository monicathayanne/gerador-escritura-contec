#  Gerador de Escrituras - CONTEC Contabilidade

Ferramenta web desenvolvida para automatizar e padronizar a criação de Escrituras Particulares de Compra e Venda.

##  Funcionalidades

* **Identidade Visual:** Personalizado com as cores e logo da CONTEC.
* **Concordância Inteligente:** Ajusta automaticamente o texto para Masculino/Feminino (Vendedor/Vendedora, Comprador/Compradora) e tipos de imóvel (Casa/Terreno).
* **Cálculos Automáticos:** Calcula a área total do imóvel com base nas medidas de frente e fundos.
* **Extenso Automático:** Converte valores numéricos (R$) e datas para escrita por extenso instantaneamente.
* **Formatação Jurídica:** Layout otimizado para impressão em papel A4, seguindo padrões de espaçamento e margens de documentos cartoriais.
* **Pagamento Dinâmico:** Gera cláusulas de pagamento à vista ou parcelado automaticamente.

##  Como Usar

1.  Acesse o link do sistema (Link do GitHub Pages).
2.  Preencha os dados no menu lateral esquerdo.
3.  Confira a pré-visualização do documento à direita.
4.  Clique no botão **"IMPRIMIR CONTRATO"**.
5.  Nas configurações de impressão, selecione **Margens: Nenhuma** para o ajuste perfeito.
